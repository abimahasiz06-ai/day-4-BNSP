# Day 4 BNSP - Aplikasi InventarisKu

## 📌 Deskripsi
Pada pembelajaran hari ke-4 BNSP, saya membuat aplikasi sederhana bernama **InventarisKu**, yaitu aplikasi berbasis web yang digunakan untuk menampilkan dan mengelola data inventaris barang.

Proyek ini menggunakan HTML untuk menyusun struktur halaman, CSS untuk mengatur tampilan agar lebih rapi dan responsif, serta JavaScript sebagai dasar pemrograman untuk mengolah data dan membuat halaman web menjadi lebih interaktif.

## 🎯 Tujuan Pembelajaran
- Memahami dasar-dasar JavaScript.
- Mengenal penggunaan variabel dan tipe data.
- Memahami penggunaan kondisi `if-else`.
- Mengenal perulangan menggunakan `for`.
- Memahami penggunaan array dan object.
- Mengenal fungsi untuk mengolah data.
- Memahami hubungan HTML, CSS, dan JavaScript dalam pembuatan aplikasi web.

## 🛠️ Teknologi yang Digunakan
- **HTML** — Membuat struktur halaman aplikasi.
- **CSS** — Mengatur desain, warna, tata letak, dan responsivitas halaman.
- **JavaScript** — Mempelajari logika pemrograman untuk mengolah data.

## ✨ Fitur dan Komponen Aplikasi
Aplikasi InventarisKu memiliki beberapa komponen utama:

1. **Ringkasan Inventaris**  
   Menampilkan informasi mengenai jumlah jenis barang, total stok, dan nilai inventaris.

2. **Form Tambah Barang**  
   Menyediakan kolom untuk memasukkan kode barang, nama barang, jumlah stok, dan harga satuan.

3. **Tabel Daftar Inventaris**  
   Menampilkan data barang dalam bentuk tabel, seperti kode barang, nama barang, stok, harga satuan, nilai stok, dan status ketersediaan.

4. **Kolom Pencarian**  
   Menyediakan tampilan kolom untuk mencari barang berdasarkan kode atau nama barang.

5. **Tampilan Responsif**  
   Menggunakan CSS agar tata letak aplikasi dapat menyesuaikan ukuran layar komputer maupun perangkat seluler.

## 📚 Materi yang Dipelajari
Dalam proses pembelajaran ini, saya mengenal beberapa konsep dasar JavaScript, yaitu:

- **Variabel dan Object:** Menyimpan data barang dalam bentuk pasangan properti dan nilai.
- **Kondisi `if-else`:** Menentukan tindakan berdasarkan kondisi tertentu.
- **Perulangan `for`:** Mengulang proses untuk mengolah atau menampilkan data.
- **Array:** Menyimpan kumpulan data barang.
- **Function:** Mengelompokkan perintah agar dapat digunakan untuk menjalankan tugas tertentu.
- **Operator:** Melakukan perbandingan dan operasi perhitungan dalam program.

## 💡 Kesimpulan

Saya juga mempelajari bagaimana HTML, CSS, dan JavaScript memiliki peran yang berbeda tetapi saling melengkapi dalam pengembangan web.

Pembelajaran ini menjadi langkah awal bagi saya untuk memahami logika pemrograman dan mengembangkan aplikasi web yang lebih interaktif pada tahap berikutnya.
